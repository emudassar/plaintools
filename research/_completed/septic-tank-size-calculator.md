## 2. The question this answers

Given the number of bedrooms in a one- or two-family home, what minimum septic tank capacity does
a recognized US design reference specify?

## 4. The data source

Not an API — a published table, same pattern as the water-softener tool.

- **Name and publisher:** *Onsite Wastewater Treatment Systems Manual*, EPA/625/R-00/008, U.S.
  Environmental Protection Agency, Office of Water and Office of Research and Development,
  February 2002. Table 4-13, "Septic tank capacities for one- and two-family dwellings," page
  4-40, which the manual itself attributes to the International Private Sewage Disposal Code
  (International Code Council, 1995).
- **Endpoint or file:**
  https://www.epa.gov/sites/default/files/2015-06/documents/2004_07_07_septics_septic_2002_osdm_all.pdf
- **Licence / terms URL:** https://www.epa.gov/web-policies-and-procedures — public US federal
  government publication
- **API key needed?** No — nothing is fetched at runtime
- **Quota or rate limit:** n/a

**Verbatim, Table 4-13, page 4-40, read directly from the rendered page image, 2026-09-26:**

| Number of bedrooms | Septic tank volume (gallons) |
|---|---|
| 1 | 750ᵃ |
| 2 | 750ᵃ |
| 3 | 1,000 |
| 4 | 1,200 |
| 5 | 1,425 |
| 6 | 1,650 |
| 7 | 1,875 |
| 8 | 2,100 |

Footnote a, verbatim: "Many states have established 1,000 gallons or more as the minimum size."

Surrounding text, verbatim and paraphrased:

> "Most state and national plumbing codes specify the tank volume to be used based on the
> building size or estimated peak daily flow of wastewater. Table 4-13 presents the tank volumes
> recommended in the International Private Sewage Disposal Code specified for one- and
> two-family residences (ICC, 1995). The volumes specified are typical of most local codes, but
> in many jurisdictions the minimum tank volume has been increased to 1,000 gallons or more."

> "For buildings other than one- or two-family residential homes, the rule of thumb often used
> for sizing tanks is to use two to three times the estimated design flow. This conservative rule
> of thumb is based on maintaining a 24-hour minimum hydraulic retention time when the tank is
> ready for pumping, for example, when the tank is one-half to two-thirds full of sludge and
> scum."

From elsewhere in the same manual (page 3-19, on estimating design flow):

> "Codes typically specify design flows of 100 to 150 gallons/bedroom/day (378 to 568
> liters/bedroom/day), or 75 to 100 gallons/person/day (284 to 378 liters/person/day), with
> occupancy rates of between 1.5 and 2 persons/bedroom (NSFC, 1995)."

From Special Issue Fact Sheet 2 (garbage grinders), on a caveat worth surfacing rather than
folding into the number:

> "Most state codes require a septic tank size increase to account for the additional volume of
> sludge and scum accumulating in a septic tank but offer no advice as to any increasing field
> size."

No specific gallon figure is given anywhere in the manual for a garbage-disposal adjustment, so
**none is invented** — the page states the fact and stops there, the same treatment the
water-softener tool gives the uncited iron-compensation figure.

## 5. It is a calculation, not an API

There is no formula to invent — the table above **is** the answer for 1–8 bedrooms. It is a
lookup, not arithmetic, which makes this closer in shape to a reference-chart tool than to the
water-softener tool's live calculation. The only computed value is the "estimated daily design
flow" supporting figure, using the manual's own stated range:

```
estimated daily design flow (low)  = bedrooms × 100 gallons/bedroom/day
estimated daily design flow (high) = bedrooms × 150 gallons/bedroom/day
```

**Worked example, by hand:** a 3-bedroom home: table capacity 1,000 gallons; estimated daily
design flow 300–450 gallons/day (3 × 100 to 3 × 150), both taken directly from the manual's
stated range with no computation invented beyond multiplication.

**Checked against which independent reference?** The table values were read twice from the
rendered page image (a second, independent render at the same DPI reproduced identical figures)
and cross-checked against the row differences (750→1,000 is +250, 1,000→1,200 is +200,
1,200→1,425 is +225, then +225 for each subsequent row) to confirm no transcription slip — the
irregular first jump (+250 then +200) is genuine, not a reading error, since it is stated
verbatim in the source image at high resolution.

## 6. The dead zone

| Input that fails | What happens | How common |
|---|---|---|
| More than 8 bedrooms | Table 4-13 has no row past 8 — **no number exists to give** | Rare for single-family but reachable |
| Fewer than 1 bedroom (0, or a non-residential building) | Table is explicitly scoped to "one- and two-family dwellings" — does not apply | Uncommon input, common real situation (e.g. a small commercial building) |
| A garbage disposal / grinder in use | The manual says state codes commonly increase tank size for this, but gives **no specific figure** | Common — most US kitchens have one |
| Multi-family, more than two units | Table 4-13 is explicitly "one- and two-family" — out of scope | Uncommon input for this tool |

- **How the fallback explains the gap in plain language:** above 8 bedrooms, the page states
  plainly that the cited table stops at 8 and shows the manual's separate rule of thumb for
  buildings other than one- or two-family homes (two to three times the estimated daily design
  flow) as a clearly labelled *different, less specific* rule — never presented as a table lookup
  it is not.
- **What the source still records when the main answer is missing:** the estimated daily design
  flow range (bedrooms × 100–150 gpd) is always computable and shown, even when the table has no
  row for the input.
- **The garbage-disposal note is shown whenever asked**, quoting the manual's sentence, with no
  invented adjustment factor — this is the same discipline the water-softener tool applies to the
  uncited iron-compensation figure.
