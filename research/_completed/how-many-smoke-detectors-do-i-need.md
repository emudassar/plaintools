## 5. Calculation

Count = sleeping rooms + one outside each separate sleeping area + one per storey (incl. basement)
not already covered. **This is the commonly published summary, unverified against the code text.**
Verify, including the split-level and "immediate vicinity" wording, before building.

## 6. The dead zone

| Input | Answer |
|---|---|
| Apartment / commercial | Out of IRC scope (IBC / NFPA 72). Say so |
| Split-level storeys | Check R314.3 wording for the split-level exception |
| 0 bedrooms (studio) | Still has a sleeping area. Handle explicitly |
| CO alarms | A separate question (R315). Not this tool |
